# Матрица решений Buy vs Build

## Цель

Определить для каждой ключевой бизнес-функции целевую модель развёртывания:
- **SaaS (Buy)** — готовые облачные решения, не требуют разработки.
- **PaaS / IaaS (Migrate / Build in Cloud)** — перенос внутренних систем в облако на управляемых сервисах.
- **In-house / On-premises** — оставить как есть, если функция является конкурентным преимуществом.

## Матрица

| L2-функция | Текущее состояние | Стратегия | Обоснование |
|-----------|------------------|-----------|-------------|
| **1.1 Обработка чека (касса)** | Толстый клиент, жёсткая привязка к USB-терминалам | **SaaS (Buy)** | Кассовая функция — стандартизирована, не даёт конкурентного преимущества. Решение: Cloud POS + Payment Gateway. |
| **1.2 Управление ассортиментом** | Ручной маппинг Excel, VLOOKUP | **PaaS (Build in Cloud)** | Маппинг — кросс-магазинный процесс. Решение: облачный сервис с AI/ML для автоматического сопоставления SKU. |
| **1.3 Программа лояльности** | Тетрадка в магазине + отдельные БД | **SaaS (Buy)** | Стандартная CRM-функциональность. Решение: облачный loyalty-сервис (например, Yandex Online Retail или аналог). |
| **2.1 Движок промоакций** | Promo Engine in-house | **In-house (Cloud Migrate)** | Уникальная бизнес-логика, конкурентное преимущество. Перенести на облачные вычисления, но сохранить код. |
| **2.2 Email / Push-рассылки** | Скорее всего, in-house или отсутствует | **SaaS (Buy)** | Стандартная маркетинговая функция. Решение: SendGrid, Amazon SES и т.п. |
| **3.1 Омниканальная доставка (Click & Collect)** | Smart Fulfillment in-house | **In-house (Cloud Migrate)** | Ключевое конкурентное преимущество. Перенести в PaaS (управляемые БД, контейнеры). |
| **3.2 Управление складом** | Локальные решения | **PaaS / SaaS (Buy)** | Стандартная складская логистика. Решение: облачный WMS (Buy) или собственная система на PaaS. |
| **3.3 Онбординг новой ТТ** | Ручной экспорт CSV → VLOOKUP → FTP | **PaaS (Build in Cloud)** | Процесс интеграции — кросс-функциональный. Автоматизировать через AI-сервисы в облаке. |
| **4.1 Инкассация** | Ручной сбор наличных | **SaaS (Buy)** | Решение: сервисы инкассации через банк (уже используется, но требует автоматизации отчётности). |
| **4.2 Расчёт премий продавцам** | Локальные серверы, ручная логика | **PaaS (Build in Cloud)** | Мigrate в облако, автоматизировать расчёт на основе данных из Cloud POS. |
| **4.3 SAP ERP** | On-premises ERP | **In-house (Cloud Migrate)** | Сердце учётной системы. Перенести на IaaS/PaaS в облако (например, SAP on Azure), но не заменять. |
| **5.1 Поддержка локальных серверов** | 500+ серверов в подсобках | **SaaS / PaaS (Buy)** | Полностью устранить: перейти на Cloud POS без локальных БД. Капитально снизить TCO. |
| **5.2 Мониторинг оборудования** | Ручной, реактивный | **SaaS (Buy)** | Решение: облачный IoT-мониторинг для фискальных регистраторов и терминалов. |
| **5.3 Управление каналами связи** | Провайдеры | **SaaS (Buy)** | Уже используется; добавить резервирование (4G/LTE fallback). |
| **6.1 M&A интеграция** | Ручной процесс | **PaaS (Build in Cloud)** | Автоматизировать через единый онбординг-пайплайн в облаке. |
| **6.2 Печать ценников** | Ручная генерация | **SaaS (Buy)** | Готовые решения для печати этикеток. Интеграция с Promo Engine. |

## Итоговая сводка

| Модель | Функции | Доля затрат, которые закрывают |
|--------|---------|-------------------------------|
| **SaaS (Buy)** | Касса, лояльность, email-маркетинг, печать ценников, мониторинг оборудования, инкассация | ~40% всех ИТ-затрат |
| **PaaS (Build in Cloud)** | Онбординг, управление ассортиментом, расчёт премий, склад | ~30% всех ИТ-затрат |
| **In-house (Cloud Migrate)** | SAP ERP, Promo Engine, Smart Fulfillment | ~30% всех ИТ-затрат (но это — конкурентные преимущества) |

## Ожидаемый эффект

- Отказ от локальных серверов → снижение CapEx и OpEx на 40%.
- Автоматизация онбординга → сокращение срока с 2 недель до 5 дней.
- Единый Cloud POS → устранение 40% бюджета на поддержку легаси-оборудования.
